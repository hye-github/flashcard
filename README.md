## 📌 프로젝트 소개

사용자가 직접 학습할 단어를 등록하고, 플래시카드 형태로 암기가 필요한 단어나 개념을 카드 형태로 관리하고 학습하는 **사용자 맞춤형 자기주도 학습 도구** 웹 애플리케이션입니다.
방대한 IT 자격증 용어의 효율적인 암기를 위해, CSV 대량 등록 기능과 Firebase 클라우드 저장을 통해 어디서나 학습 데이터에 접근할 수 있도록 구현하였습니다.

## ✨ 주요 기능

📝 카드 관리
- **CRUD 기능** — 카테고리별 단어/정의 추가, 수정, 삭제
- **일괄 관리** — 다중 선택 삭제 및 전체 선택/해제
- **CSV 지원** — Excel 파일 업로드/다운로드 (UTF-8 BOM 인코딩)
- **중복 검사** — CSV 업로드 시 기존 단어 중복 방지

🎯 학습 기능
- **3D 카드 뒤집기** — 클릭/터치로 단어↔정의 전환
- **출력 모드** — 용어→정의 / 정의→용어 / 랜덤 모드 지원
- **즐겨찾기** — 중요한 카드만 필터링하여 학습
- **랜덤 섞기** — 매 세션마다 카드 순서 자동 변경

📱 UX/UI

- **반응형 디자인** — PC/모바일 최적화
- **모바일 제스처** — 좌우 스와이프로 카드 넘기기
- **관리자 인증** — Firebase Authentication (이메일/비밀번호)
- **실시간 동기화** — Firebase Firestore로 모든 기기에서 데이터 공유
