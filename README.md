## 📌 프로젝트 소개

사용자가 직접 학습할 단어를 등록하고, 플래시카드 형태로 암기가 필요한 단어나 개념을 카드 형태로 관리하고 학습하는 **사용자 맞춤형 자기주도 학습 도구** 웹 애플리케이션입니다.
방대한 IT 자격증 용어의 효율적인 암기를 위해, 엑셀 대량 등록 및 브라우저 로컬 저장 기능을 갖춘 학습 도구를 구현하였습니다.

---

## ✨ 주요 기능

- **CRUD 기반 카드 관리** — 단어/뜻 추가, 개별 삭제 및 전체 삭제 기능
- **Excel 업로드** — Excel에 단어를 입력하여 대량 등록 가능
- **상태 관리** — LocalStorage를 활용해 브라우저를 닫아도 학습 데이터 유지
- **인터랙티브 UI** — 카드 뒤집기 애니메이션, 입력 폼 토글 모달, 반응형 레이아웃 구현
- **사용자 경험(UX)** — 데이터가 없을 시 안내 문구 표시, 직관적인 카드 추가 인터페이스

---

## 💡 개발 방식

Claude AI를 활용한 **바이브코딩** 방식으로,
초기 아이디어 기획부터 UI 애니메이션 구현, 배포까지 **3일 내 완료**하였습니다.
